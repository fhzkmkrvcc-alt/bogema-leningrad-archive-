# Архив — сайт-каталог одежды

Публичный каталог с поиском, страницами предметов, загрузкой нескольких фотографий и закрытым входом администратора. Интерфейс на русском языке, светлый минималистичный стиль.

## Важно
Проект готов как исходный код, но он не опубликован в интернете и не подключён к вашей базе данных. Для постоянного хранения и защищённого доступа потребуется настроить Supabase и разместить сайт, например, на Vercel.

## 1. Подготовить базу данных
1. Создайте проект в Supabase.
2. Откройте **SQL Editor**, вставьте содержимое `supabase.sql` и выполните.
3. В **Authentication → Users** добавьте своего пользователя (email + пароль). Отключите публичную регистрацию, если она не нужна.
4. В **Project Settings → API** скопируйте Project URL и publishable/anon key.
5. Скопируйте `.env.example` в `.env` и вставьте эти значения. Никогда не помещайте `service_role` key в клиентский сайт.

## 2. Запустить на компьютере
Установите Node.js (LTS), затем в папке проекта выполните:
```bash
npm install
npm run dev
```
Vite покажет локальный адрес, который можно открыть в браузере.

## 3. Опубликовать
1. Загрузите папку проекта в собственный GitHub-репозиторий.
2. Импортируйте репозиторий в Vercel.
3. В настройках проекта Vercel добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
4. Запустите deployment. После публикации любой сможет просматривать каталог; только пользователи, вошедшие через Supabase Auth, смогут добавлять, редактировать и удалять записи.

## Безопасность
Доступ к изменению данных проверяется на стороне Supabase через Row Level Security, а не только скрытием кнопок в интерфейсе. Перед публичным запуском проверьте политики и добавьте в Authentication только свой аккаунт. Этот стартовый проект предполагает, что все авторизованные аккаунты являются администраторами; не создавайте дополнительные аккаунты, если хотите единственного администратора.
